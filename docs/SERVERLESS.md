# 无服务端折中方案指南 (Serverless Direct Guide)

XiaobaoDesk 默认**不依赖任何中心服务端或云服务器**。只要手机与电脑之间能够通过任意 IPv4 / IPv6 / 虚拟网卡建立 TCP 21118 连接，即可完成全加密 TLS 1.3 串流、终端与文件传输。

以下按推荐优先级提供 4 种零服务器或免购置服务器折中方案：

---

## 方案对比总览

| 方案 | 是否需要服务器 | 适用场景 | 预期延迟 | 配置难度 |
| :--- | :---: | :--- | :---: | :---: |
| **1. 局域网 / 手机热点 UDP 自动发现** | 否 | 同处家中/办公室 Wi-Fi 或手机开热点 | 1 ~ 5 ms | ⭐ 极简 |
| **2. 运营商公网 IPv6 + 免费 DDNS** | 否 | 手机 4G/5G 在外直连家里宽带电脑 | 15 ~ 40 ms | ⭐⭐ 简单 |
| **3. Tailscale / ZeroTier 虚拟组网** | 否（用免费 SaaS 组网） | 对称型 NAT / 校园网 / 公司内网 | 20 ~ 60 ms | ⭐⭐ 简单 |
| **4. 免费 TCP 隧道 / 自建 `xb-hub`** | 轻度 | 无 IPv6 且不想装组网软件的兜底 | 30 ~ 90 ms | ⭐⭐⭐ 中等 |

---

## 方案一：同局域网 / 手机热点直连（零配置）

1. 确保电脑端已运行 `scripts\setup-win-host.ps1`（放行 **TCP 21118** 与 **UDP 21118**）。
2. 在手机端 **「连接」** 页点击 **「局域网发现」**，App 会广播 `xb_discover` 探测包，自动填充电脑的局域网 IP、Host ID 与 TLS 证书指纹，你只需输入密码即可连接。
3. 也可在电脑上运行 `scripts\start-local-pairing.ps1`，用手机浏览器打开提示的本地 URL，一键离线导入全部配置。

---

## 方案二：原生公网 IPv6 + 免费 DDNS（外网直连满速）

国内三大运营商宽带及手机 4G/5G 现已普遍分配公网 IPv6：
1. 在光猫/路由器中关闭“IPv6 入站全拦截”或放行电脑的 `TCP 21118` 端口。
2. 在电脑上使用任意免费 DDNS 工具（如 `ddns-go` 配合 Cloudflare / 阿里云 / 腾讯云 / DuckDNS）将动态 IPv6（AAAA 记录）绑定到你的域名，如 `pc.example.com`。
3. 在手机端配置的 **「直连地址」** 填入 `pc.example.com:21118`（**「自建 Hub 地址」留空**），客户端会自动解析其 AAAA/A 记录并发起 TLS 1.3 直连。

---

## 方案三：Tailscale / ZeroTier 免费虚拟局域网（穿透任意复杂 NAT）

如果公司/校园网屏蔽了入站 IPv6 或处于多层对称 NAT：
1. 在 Windows 电脑和 Android 手机上分别安装 **Tailscale**（或 ZeroTier）并登录同一账号。
2. 电脑端会获得一个固定虚拟内网 IP（如 `100.x.y.z`）。
3. 手机端配置的 **「直连地址」** 填入 `100.x.y.z:21118`（支持多地址逗号分隔，例如 `192.168.1.50:21118, 100.x.y.z:21118`，App 会并发竞速连接，局域网优先、外网自动走组网通道）。

---

## 方案四：免费 TCP 隧道 或 轻量自建 `xb-hub`

- **TCP 隧道（frp / Cloudflare Tunnel / SakuraFrp / Natapp）**：将本机 `127.0.0.1:21118` 映射为公网 `host:port`，手机端 **「直连地址」** 填入该映射地址即可（TLS 1.3 与证书指纹校验依然端到端生效，隧道中转方无法解密画面与密码）。
- **自建 `xb-hub`**：若已有任意 Linux VPS，可直接运行 `hub/` 编译出的单二进制文件（参考 `deploy/deploy-hub-example.sh`），同时获得端点打洞信令与 TLS 1.3 中继兜底。
